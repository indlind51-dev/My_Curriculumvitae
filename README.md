# My Curriculum Vitae

Website CV pribadi milik Muhammad Indra Herlambang yang dikembangkan sebagai portofolio online untuk memperkenalkan profil, riwayat pendidikan, pengalaman kerja, dan keahlian di bidang teknologi informasi.

**Fitur Website:**
- Profil dan informasi pribadi.
- Riwayat pendidikan.
- Pengalaman sebagai teknisi komputer dan printer.
- Keahlian troubleshooting dan jaringan komputer.
- Informasi kontak dan media sosial.

**Teknologi yang Digunakan:**
- HTML
- CSS
